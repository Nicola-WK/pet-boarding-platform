# 宠爱管家小程序视觉规范

参考概念：[首页](miniapp-home-concept.png)、[寄养列表](miniapp-list-concept.png)、[商家详情](miniapp-provider-concept.png)。概念图用于视觉方向，里面的示例商家、价格、距离和评价都不作为真实产品数据；页面只展示接口返回的业务内容。

## 设计系统

- 背景 `#FFFDF9`；主文字 `#2C2420`；次要文字 `#7F7772`；主操作珊瑚色 `#EE765B`；浅桃色 `#FFF0EA`；分割线 `#EFE8E3`。
- 内容区域使用约 32rpx 横向留白。标题 42–52rpx，列表标题 32–36rpx，正文 28–30rpx，辅助信息 23–25rpx。中文优先使用系统无衬线字体。
- 图片以 16–24rpx 圆角显示；主要按钮使用 100rpx 左右的全圆角。页面避免重复叠加卡片和装饰性渐变。
- 首页以宠物合照作为唯一主要视觉画面。商家与服务列表以图片、名称、地点、单价和明确的下一步操作构成；没有数据时显示诚实的空状态。
- 四个主入口：首页、寄养、订单、我的。底部导航由共享组件实现；详情与表单保留系统返回导航。
- 设计稿中的插画图标改用统一的 `uni-icons` 线性图标与文字，真实图片优先使用商家提供的 HTTPS 地址。未提供图片时使用项目内的宠物合照作为回退图。

## 页面与交互

首页：搜索入口、宠物类别、推荐商家。寄养列表：搜索、类别和价格筛选、商家卡片。商家详情：图片、地址、服务、评价和预约入口。下单：服务、宠物、入住/离店日期、金额预览、提交。订单：状态筛选、详情、取消及可关闭的模拟支付。宠物：列表与表单。个人中心：微信登录、资料、商家申请和管理入口。商家管理：申请/编辑资料、服务管理、订单履约。评价：已完成订单评价表单与公开列表。
