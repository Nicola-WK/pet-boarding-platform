# 宠爱管家｜简历项目说明

**项目名称：**宠爱管家——宠物寄养预约微信小程序（个人全栈项目）  
**技术栈：**Java 17、Spring Boot 3、Spring Security、JWT、MyBatis-Plus、MySQL 8、Flyway；uni-app、Vue 3、TypeScript、Pinia、uni-ui。

**项目描述：**面向宠物主人与寄养商家，开发包含商家与服务浏览、宠物档案、寄养预约、订单履约和服务评价的双角色小程序。项目提供独立的本机演示模式，支付环节使用模拟支付，不涉及真实资金交易。

**个人工作与技术亮点：**

- 独立完成前后端及数据库设计，使用 Flyway 管理 9 张业务表；实现统一响应、业务异常处理、微信登录接口及基于 JWT 的接口鉴权。
- 设计寄养订单状态流转，支持下单、模拟支付、商家确认、开始寄养、完成和评价；通过价格快照、15 分钟支付时限、逐日容量校验和数据库行锁控制预约冲突。
- 基于 uni-app、Vue 3 和 TypeScript 实现 13 个小程序页面，使用 Pinia 管理登录状态，封装请求层并贯通用户、商家两侧操作流程。
- 为无小程序 AppID 的展示场景实现默认关闭的本机演示登录与模拟支付，准备 4 家商家、10 项服务及关联的示例数据；完成 78 项后端自动化测试，并在真实 MySQL 环境验证主要接口。

> 使用时请保留“模拟支付”和“本机演示”的表述；项目尚未接入真实微信支付，也未验证正式小程序账号下的真机发布流程。
